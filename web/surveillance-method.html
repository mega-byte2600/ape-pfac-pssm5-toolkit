How-to • PubMed • My NCBI • Outlook • Zotero

Build a literature surveillance system you can actually run every week.

This guide shows exactly how to create a repeatable evidence pipeline: build saved PubMed searches, turn them into My NCBI alerts, route the alerts automatically in Outlook, curate high-value studies into My NCBI collections, and maintain a shared Zotero library.

Purpose

Three connected layers create one reproducible system.

Search system

PubMed + My NCBI

Saved searches act as a continuous surveillance engine. Each query watches a specific domain and sends new results automatically.

Intake system

Email + Outlook rules

Each alert is routed to a matching folder using the saved-search name in the email subject line, keeping streams separate and reviewable.

Knowledge system

Collections + Zotero

Saved searches capture incoming evidence. Collections and Zotero organize the studies that actually matter into a reusable evidence base.

System flow: PubMed → My NCBI alert → email → Outlook rule → review folder → human screening → My NCBI collection → shared Zotero library → annotated bibliography, executive synthesis, and toolkit updates.

Do this

Run the query in PubMed.

Check that the results are broadly on-topic. If the search is too narrow, remove unnecessary restrictions. If it is too broad, refine the topic terms before saving it.

Why

Keep capture broad.

The saved search is the surveillance layer. Human screening and collections decide what is actually retained, so the capture step should not be over-filtered.

Step 2

Save the searches in My NCBI and turn on alerts.

  1. Sign in to My NCBI.

    Run the PubMed search while signed in.

  2. Save the search.

    Use the saved-search function in PubMed/My NCBI and give the search a clear, stable name.

  3. Enable email alerts.

    Choose email delivery, use Abstract format, and request approximately 25 to 100 items so enough context is available for screening.

  4. Set the cadence.

    High-volume master and experience streams are reviewed weekly. More targeted streams are reviewed monthly.

Step 4

Create one Outlook rule per saved search.

The logic is intentionally simple so it is reproducible.

Condition

Subject contains saved-search name.

Use the exact My NCBI saved-search name as the subject-match condition.

Action

Move to matching folder.

Route the alert into the folder assigned to that search stream.

Option

Stop processing more rules.

This prevents one message from being moved again by a later rule.

Example rule

Rule name:
RULE_APE_MASTER_PFAC_Inpatient_Experience_Safety

Condition:
Subject contains APE_MASTER_PFAC_Inpatient_Experience_Safety

Action:
Move to APE_ALERTS_MASTER

Option:
Stop processing more rules

Result: PubMed → My NCBI alert → email → Outlook rule → matching review folder.

Step 5

Create My NCBI collections for what you decide to keep.

Saved searches capture incoming evidence. Collections are different: they are the curated knowledge buckets containing studies that passed human review.

  1. Open PubMed.

    Collections are created from PubMed, not from the My NCBI dashboard alone.

  2. Run a search and select an article.

    Choose at least one record you want to retain.

  3. Select Send to → Collections.

    Create a new collection or add the article to an existing one.

Step 6

Use a simple curation decision engine.

Include

Keep studies that fit the practice question.

Hospital or inpatient studies; interventions and toolkits; system-level research; PFAC or engagement studies; and work linking experience, safety, access, or implementation.

Exclude

Remove clearly off-scope material.

Out-of-hospital settings, irrelevant populations, and material that does not inform the defined practice question or evidence map.

Guardrail

Do not use filters as the methodology.

Humans-only, systematic-review/meta-analysis, and free-full-text filters are temporary tools for curation, validation, or reading. They are not part of the core search methodology.

Step 7

Run the system on a small, predictable cadence.

Weekly, about 10–15 minutes: open Outlook, review APE_ALERTS_MASTER and the high-volume experience stream, scan titles and abstracts, identify high-signal records, open them in PubMed, and route accepted studies into the appropriate collections.

Monthly validation: review APE_ALERTS_SR and the other targeted streams, then confirm that systematic reviews or higher-level evidence still align with the working evidence base.

Is this study relevant to the defined practice question?
Does it change, strengthen, or challenge the current evidence base?
Which collection should receive it?
Should it update the bibliography, executive summary, matrix, or toolkit?

Step 8

Use Zotero as the shared working library.

My NCBI collections organize evidence inside PubMed. Zotero adds collaboration, tagging, annotations, citation management, and a shared source trail.

Add

Send accepted articles to Zotero.

Add records directly from PubMed using the Zotero browser connector or citation export.

Tag

Use topic tags.

Tag sources with terms such as PFAC, experience, PSSM, implementation, safety, access, or other project-specific domains.

Share

Create a group library.

The APE used the shared group library “Bolton TDI APE 27” with the preceptor. Another researcher can reproduce the same approach with a project-specific shared group library.

Maintain

Annotate and update.

Use the shared library as the working evidence base for annotations, bibliography development, cross-topic filtering, and review with collaborators.

A surveillance system is useful only if it feeds the work.

Output

Output

New evidence can be incorporated into the executive summary when it materially changes the findings.

Output

PSSM / PFAC roadmap inputs

Output

Reproducible research pipeline

The same skeleton can be reused for another APE, ILE, public-health question, or health-system improvement topic by changing queries, folders, collections, and tags.

Adapt it

Keep the architecture. Change the topic.

  1. Replace the topic terms in the PubMed query.

    Keep the Boolean structure and database-specific field logic, but use terms relevant to the new research question.

  2. Rename the saved searches and Outlook folders.

    Use a consistent naming convention so each alert can be matched reliably to one folder.

  3. Create collections that reflect the new evidence domains.

    Collections should represent the decisions the researcher needs to make, not just broad subject labels.

  4. Keep human curation in the loop.

    Automation captures and routes evidence; the researcher still decides what is relevant, how strong it is, and where it belongs.
