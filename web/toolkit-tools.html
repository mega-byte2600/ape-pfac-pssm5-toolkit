Tool 6

90-day PFAC operating plan.

Sequence the first implementation cycle so leaders validate the current state, launch one bounded workstream, assign ownership, define measures, and close the first report-back loop before expanding scope.

Days 0–30

Validate current state

Confirm sponsorship, authority, representation, participation barriers, committee interfaces, agenda pipeline, and available measures.

Days 31–60

Run one workstream

Bring one substantive problem to the PFAC before final decisions, document recommendations and disposition, and assign owners and due dates.

Days 61–90

Close the learning loop

Review implementation evidence, unresolved barriers, project signals, and report-back completion, then decide what to adapt or expand.
