Open methodology, private repository

Transparency comes from the public evidence system, not exposing the codebase.

This project shares the research method, source cataloging logic, benchmark framework, SQL examples, evidence matrix, public sources, and toolkit structure so others can adapt the approach.

The GitHub repository remains hidden from the public reviewer flow to protect project administration, draft work, deployment configuration, and development history. The website is the public source of record.
