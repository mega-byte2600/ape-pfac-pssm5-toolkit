Six decisions to make before calling a PFAC operational.

Current Dartmouth Health use case

Start with access and navigation because the local evidence is already actionable.

The 2025 Upper Valley CHNA provides a defensible starting problem: primary-care access, system navigation, capacity, wait times, rurality, isolation, and participation barriers. The APE local analysis already translates those signals into a populated PFAC implementation case.

90-day operating plan

Move from current state to one measurable PFAC workstream.

Days 0–30

Validate the operating conditions.

Confirm executive sponsor, PFAC purpose, charter and authority, current composition, participation barriers, committee interfaces, existing agenda pipeline, and available measures. Do not score unknowns as failures; document evidence state and gaps.

Days 31–60

Launch one bounded workstream.

Select one current problem, recruit the needed perspectives, bring the issue to the PFAC before decisions are final, document recommendations and leadership disposition, and assign accountable owners and due dates.

Days 61–90

Close the first learning loop.

Review action status, implementation evidence, unresolved barriers, and report-back completion. Adjust the workstream and PFAC operating model based on what was learned before expanding scope.

Leadership standard

A PFAC should create inspectable decisions, not just meetings.

The practical test is whether a leader can trace a patient or family signal to a decision pathway, accountable owner, documented disposition, implementation evidence, measurement, and report-back. The toolkit is designed to make that chain visible.
