Collaboration principle

Open source the method, not the administration.

The public website is the source of record. The collaboration workspace is the working room. The GitHub repository remains hidden from the public reviewer flow.

The project is transparent because it publishes the research surveillance method, source cataloging logic, evidence matrix, benchmarking framework, SQL starter schema, bibliography, and implementation tools. It does not need to expose code, credentials, deployment configuration, draft notes, or project administration to contribute value.

Who can contribute

A practical workspace for people who improve care.

Guardrails

Transparent does not mean uncontrolled.

Please do not submit PHI, confidential health system records, private patient details, unpublished internal documents, credentials, screenshots from restricted systems, or non-public meeting notes. The collaboration layer is for public sources, de-identified insights, implementation ideas, and shared learning.
