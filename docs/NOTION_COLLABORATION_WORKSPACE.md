## Databases

### Source Intake

Use for public articles, PubMed records, public toolkits, reports, policy links, and suggested citations.

Core fields:

- Title
- Source type
- Author or organization
- Year
- DOI
- PMID
- URL
- Submitted by
- Topic lane
- Status
- Reviewer notes

Views:

- New submissions
- Needs review
- Accepted
- Excluded
- By topic lane

### Benchmark Notes

Use for Dartmouth Health and external PFAC, patient engagement, care partner, and co-production examples.

Core fields:

- Organization
- Program or model
- Public link
- Engagement type
- Governance connection
- Safety input
- Equity or representation note
- Measurement approach
- Closed-loop evidence
- DH relevance
- Status

Views:

- Dartmouth Health assets
- External examples
- Strong examples
- Needs follow-up

## Guardrail

Do not submit PHI, confidential health system records, private patient details, unpublished internal documents, credentials, screenshots from restricted systems, or non-public meeting notes.

Use public sources, de-identified themes, implementation ideas, and collaborative learning notes only.

## Contributor onboarding message

Thank you for contributing to the PFAC PSSM 5 Collaboration Workspace. This workspace supports public evidence review, benchmarking, and toolkit improvement. Please use public sources and de-identified ideas only. The public website remains the source of record. Accepted contributions may be incorporated into the evidence matrix, benchmark assessment, bibliography, or toolkit assets.
